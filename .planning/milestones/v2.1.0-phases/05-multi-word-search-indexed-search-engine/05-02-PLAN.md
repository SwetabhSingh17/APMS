### Pages to Integrate
1. `client/src/pages/student-topics.tsx`:
   - Topic catalog search: Title, Description, Technology stack, Topic code (PUGID).
2. `client/src/pages/projects.tsx`:
   - Student projects & supervisor topics search: Title, Description, Tech stack, Student Name, Roll/Enrollment, Supervisor Name, Team ID.
3. `client/src/pages/manage-project.tsx`:
   - Team search: Team name, Project team ID, Topic title, Topic code, Supervisor name, Member names & enrollments.
   - Supervisor selection dialog search: Full name with prefix, designation, department, email.
   - Assign topic modal search: Topic code, title, domain, technology, proposer name.
4. `client/src/pages/team-management.tsx`:
   - Teams directory search: Team name, Project team ID, Topic title, Topic code, Supervisor name, Member names, enrollments, emails.
   - Change supervisor modal search: Full name with prefix, designation, department.
5. `client/src/pages/supervisor-management.tsx`:
   - Supervisors directory search: Prefix, Name, Emp ID, Designation, Department, Email, Mobile, Topics, Teams.
   - Direct team allotment dialog search: Team name, Project team ID, Supervisor name, Member names & enrollments.
   - General team allotment search.
6. `client/src/pages/user-management.tsx`:
   - Users directory search: Username, First Name, Last Name, Full Name, Email, Enrollment Number, Emp ID, Mobile, Course, Department.
7. `client/src/pages/approve-topics.tsx`:
   - Pending/Approved/Rejected topics search: Title, Description, Topic code, Technology, Supervisor/Proposer full name with prefix.
8. `client/src/pages/track-progress.tsx`:
   - Track progress table search: Topic title, Topic code, Student full name, Enrollment number, Technology, Supervisor full name.
9. `client/src/pages/supervisor-evaluations.tsx`:
   - Project search: Topic title, Student full name, Enrollment number, Team ID.
10. `client/src/pages/notifications.tsx`:
    - Notification search: Title, Message, Type.
