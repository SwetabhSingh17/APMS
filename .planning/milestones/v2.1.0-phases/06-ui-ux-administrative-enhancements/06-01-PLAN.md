### Root Cause Analysis & Changes
1. **Navigation Pane Reorganization & Label Renaming**:
   - In `client/src/components/layout/sidebar.tsx`, the labels "Main Navigation", "Manage Project", and "Setting" need to be updated.
   - "Manage Project" needs to be grouped under the "Management" section.
2. **Admin & Coordinator Direct Topic Creation with Faculty Assignment**:
   - In `client/src/pages/topics.tsx`, the UI currently only allows approving or rejecting topics submitted by supervisors.
   - We need to add a "Create Topic" button/modal for Admins/Coordinators that mirrors the supervisor topic submission form but includes a "Faculty/Supervisor" selector.
   - Submitting this form should call an endpoint (e.g., `POST /api/topics/admin` or similar) in `server/routes/topics.ts`.
   - The backend `createTopic` (or a new admin specific method in `server/db-storage.ts`) should create the topic, auto-approve it, and assign it to the selected faculty supervisor.
</context>
