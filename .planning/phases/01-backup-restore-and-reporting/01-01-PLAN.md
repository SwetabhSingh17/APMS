### Current State & Limitations
1. `exportData()` in `server/db-storage.ts` lines 1662-1677 only selects from 5 tables (`users`, `projectTopics`, `studentProjects`, `studentGroups`, `studentGroupMembers`).
2. `projectAssessments` (student marks, faculty evaluation feedback), `projectMilestones` (project deliverables and due dates), and `notifications` (system audit messages) are completely omitted.
3. The previous endpoint returned a single flat JSON response without folder structuring, table separation, SQL fallback dump, or manifest checksums.
4. The live production database is actively running with real student data, so all export operations must be strictly read-only and non-blocking.

### Target Architecture
1. **Full 8-Table Data Extraction:**
   - Query all 8 primary tables:
     - `student_groups`
     - `users`
     - `student_group_members`
     - `project_topics`
     - `student_projects`
     - `project_assessments`
     - `project_milestones`
     - `notifications`
   - Include metadata: export timestamp, total record counts per table, portal identity (`IU-APMP`), and schema version.
2. **Archive / Folder Packaging:**
   - Package the export into a downloadable ZIP archive (or structured multi-file bundle) containing:
     - `manifest.json`: summary of all tables, record counts, timestamp, portal name, version.
     - `tables/users.json`
     - `tables/student_groups.json`
     - `tables/student_group_members.json`
     - `tables/project_topics.json`
     - `tables/student_projects.json`
     - `tables/project_assessments.json`
     - `tables/project_milestones.json`
     - `tables/notifications.json`
     - `portal_full_backup.json`: single combined JSON file matching previous format for 100% backward compatibility.
     - `backup_recovery.sql`: raw SQL insert statements for offline `psql` command-line recovery.
3. **Local Server Persistence:**
   - Automatically write a copy of the backup package into `database/backups/IU-APMP_backup_[timestamp].zip` (or `.json`) so the server administrator always has a local recovery point even if browser download is lost.
