### UI Requirements
1. **Card 1: Complete A-Z Backup & Export:**
   - Title: "A-Z Portal Backup & Export"
   - Description: "Download a complete, all-inclusive backup package (ZIP / JSON) containing all 8 database tables, milestones, evaluation history, notifications, and emergency SQL recovery scripts."
   - Action: "Backup & Export Portal" with download progress state.
2. **Card 2: Multi-Page University Excel Export:**
   - Title: "University Excel Report (Multi-Sheet)"
   - Description: "Generate an official university workbook containing 8 dedicated worksheets: Summary KPIs, Students Master, Faculty Supervisors, Project Teams, Topics Catalog, Allocations, Evaluations & Marks, and Milestones."
   - Action: "Export University Report (.xlsx)" with loading state.
3. **Card 3: High-Fidelity Import & Restore:**
   - Title: "Portal Import & Restore"
   - Description: "Restore system from a complete backup package with strict foreign key dependency ordering, automatic sequence re-sync, and automated pre-restore safety snapshot."
   - Action: "Import & Restore" opening pre-flight modal:
     - Drag & drop / file picker for `.zip` or `.json` backup file.
     - Pre-flight preview card parsing and displaying: Backup Date, Schema Version, Record Counts (Users, Teams, Topics, Projects, Marks, Milestones, Notifications).
     - Explicit warning notice: "An automatic safety snapshot of the current live database will be created before applying this restore."
     - Restore progress indicator and instant in-place cache invalidation (admin session preserved).

### Verification Script (`scripts/verify_backup_and_excel_export.ts`)
- Tests:
  1. Test `storage.exportData()` extracts all 8 tables with non-null arrays and records metadata.
  2. Test `storage.createFullBackupPackage()` creates zip archive containing manifest.json and table files.
  3. Test `storage.generateUniversityExcelReport()` produces workbook containing all 8 distinct sheets.
  4. Test topological ordering logic and verify sequences align safely.
  5. Verify live production database is unmodified and zero records are lost.
